## Caveats

- Scorable set: 1001 of 1749 fixtures with a `human_mapping.json`. 748 are unscorable: 746 because difffold has no parser for the language here (.cpp 71, .cs 81, .kt 58, .sh 54, .html 57, .json 52, .php 46, .rb 43, .swift 41, .lua 40, .xml 39, .css 38, .vim 33, .yml 28, .scala 20, others fewer; see `unscorable.csv`), and 2 because the ground truth has no pairs. A fixture is also unscorable if OmniDiff's own node counts differ from difffold's parse; **no fixture was dropped for that reason** (0 node-count mismatches). One further fixture (`handmade/bazel-not-actually-supported-by-treesitter`) failed in omni_dump with "no ast" and is in the unsupported-language group. The result therefore covers only the 8 languages difffold parses (c, go, java, javascript, python, rust, tsx, typescript); Java is 515 of the 1001, so micro numbers are Java-weighted.
- Ground truth is the mapping hand-authored by OmniDiff's own authors, with OmniDiff's notion of "visible" nodes. This favours OmniDiff in what counts as a correct choice for ambiguous cases (e.g. wrap/unwrap, group matches), and OmniDiff was tuned against this corpus. Treat OmniDiff's numbers as an in-sample upper-end and the comparison as favourable to it.
- Calibration: on 1001 fixtures the scorer's OmniDiff visible-mismatch total (3405) equals OmniDiff's native checker (3405), zero/non-zero agreement 100.0%. The scorer ignores operation kinds (Identical vs Update) and the subtree-closure step of groups, which the native checker enforces.
- Metric definitions: pair P/R/F1 compare a tool's matched node pairs to ground-truth pairs (all tree-sitter nodes, preorder). Node-correspondence accuracy is the fraction of graded decisions (pair, delete, insert, group-member) judged correct. Changed-span F1 is over tokens (leaves that are not whitespace, comments or punctuation); a token is "changed" when unmatched or no partner has the same label; moved identical tokens are unchanged. Perfect = zero visible mismatches; near-perfect and strict-perfect as defined in the scorer. Micro sums over fixtures; macro averages per-fixture values.
- Build note: `tools/omni_dump/Cargo.toml` needed a `[profile.ci]` section (inherits release, lto off, codegen-units 16) because profiles apply only from the workspace root and omni_dump is its own workspace. This edit is uncommitted. The scorer writes `summary_tables.md` rather than SUMMARY.md.
